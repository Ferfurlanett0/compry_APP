1. Visão Geral
1.1 Objetivo do Produto
O ListaPro é um aplicativo Android desenvolvido para facilitar a comunicação entre funcionários e o
responsável pelas compras de um estabelecimento.
Atualmente, os pedidos de compras são enviados via WhatsApp em mensagens de texto, o que gera
diversos problemas:
mensagens perdidas;
itens esquecidos;
ausência de confirmação em tempo real;
dificuldade para localizar pedidos antigos;
impossibilidade de acompanhar o andamento da compra;
falta de padronização das solicitações.

O objetivo do ListaPro é centralizar todo esse fluxo em um único aplicativo, proporcionando
organização, rastreabilidade, histórico e acompanhamento em tempo real.
1.2 Contexto
O primeiro cliente será uma churrascaria.
O funcionamento atual ocorre da seguinte maneira:
A cozinheira cria uma lista de compras.
O churrasqueiro também pode criar listas.
Ambos enviam essas listas pelo WhatsApp.
O proprietário visualiza as mensagens.
Durante a compra ele tenta lembrar quais itens já pegou.
Não existe confirmação em tempo real.
Não existe histórico organizado.
Esse processo gera retrabalho e aumenta a chance de esquecer produtos importantes.
2. Problema Atual
Principais dores
Organização
As listas ficam espalhadas em diversas conversas.
Controle
Não existe um checklist durante a compra.
Comunicação
Não é possível saber se um item já foi comprado.
Histórico
Não há um banco de dados de pedidos anteriores.
Padronização
Cada funcionário escreve a lista de uma forma diferente.

3. Objetivos do Produto
Objetivos principais
Eliminar o uso do WhatsApp para envio das listas.
Organizar todos os pedidos em um único ambiente.
Permitir acompanhamento em tempo real.
Melhorar a produtividade.
Reduzir esquecimentos.
Criar um histórico permanente.
Permitir funcionamento offline.
Criar uma arquitetura preparada para crescimento.
Objetivos secundários
Interface extremamente simples.
Curva de aprendizado praticamente inexistente.
Aplicativo rápido.
Sincronização automática.
Alta confiabilidade.
4. Escopo do MVP
O MVP deverá conter apenas as funcionalidades essenciais.
Autenticação
Login com usuário e senha.
Não haverá cadastro pelo aplicativo.
Todas as contas serão cadastradas manualmente pelo administrador.
O aplicativo nunca exibirá botão "Criar Conta".
Perfis
Existirão duas permissões.
Administrador
Responsável pelas compras.

11. Regras Gerais do Sistema
RG-001
O aplicativo não permitirá criação de contas pelo usuário.
RG-002
Todos os usuários serão cadastrados manualmente pelo administrador do sistema.
RG-003
Toda lista deverá possuir obrigatoriamente um título.
RG-004
Toda lista deverá conter pelo menos um item.
RG-005
Somente o administrador poderá finalizar uma lista.
RG-006
Os funcionários poderão acompanhar a compra em tempo real.
RG-007
As alterações deverão ser sincronizadas automaticamente quando houver internet.
9
RG-008
Caso o dispositivo esteja offline, todas as alterações deverão ser armazenadas localmente e
sincronizadas assim que a conexão for restabelecida.
RG-009
Nenhum item poderá ser excluído após a finalização da lista.
RG-010
Todo evento relevante deverá possuir registro de data e hora.
Exemplos:
criação da lista;
envio;
início da compra;
marcação de item;
conclusão.
12. Glossário
Termo
Definição
Lista
Conjunto de itens solicitados por um funcionário.
Item
Produto individual pertencente a uma lista.
Funcionário
Usuário responsável por criar listas.
Administrador
Usuário responsável por realizar as compras.
Categoria
Agrupamento de itens semelhantes.
Checklist
Marcação de produtos já comprados.
Offline
Funcionamento sem conexão com a internet.
Sincronização
Envio automático das alterações ao Firestore quando houver conexão.
